## What to compare

- Recognition: is there a visual idea someone could describe without reading the logo?
- First impression: does the opening establish JavaScript/application structure and an agent angle?
- Craft: do type, spacing, illustration, controls, and documentation feel related?
- Explanation: does the visual idea help explain ownership and lifecycle?
- Tone: is the humor sparse and candid, with no invented proof of agent outcomes?
- Usability: readable mobile layout, working controls, keyboard focus, reduced motion.

The static illustration is metaphorical. Only the real View/Region demo is evidence
of library behavior. Agent migration or productivity claims still need experiments.
